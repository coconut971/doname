# Agent Plugins 1.0.0 schemas

These two JSON Schemas are copied unchanged from the canonical
[Agent Plugins 1.0.0 schema URLs](https://agent-plugins.org/schemas/).
They are used only for local/CI validation of DoName's manifests. The
[Agent Plugins specification repository](https://github.com/agentplugins/agent-plugins-spec/blob/main/LICENSE.md)
licenses schemas under Apache License 2.0; its license text is included here.
The validator pins each file's SHA-256 hash. Runtime plugin loading makes no
schema request.
